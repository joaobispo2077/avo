# Guidelines: --youtube

YouTube format diagnosis and playbook routing.

## Load

- [`AGENTS.md`](../../../AGENTS.md) editorial rules
- Skills when available: `youtube-format-selection`, `youtube-format-playbooks`, `retention-diagnostics`

## Diagnosis checklist

1. **Primary format** (and hybrid sections if any): review, news, documentary, list, performance, …
2. **Viewer intent:** learn, decide, follow news, be entertained, connect, analysis, performance
3. **Title/thumbnail promise:** what must pay off?
4. **Pacing density:** meaningful change over time, not cut frequency
5. **Traffic posture:** search-led, browse-led, subscriber-led, trend-led, community-led
6. **Risks:** rights, reused content, sponsorship disclosure, AI disclosure, made-for-kids

## Playbook application

- Apply the matching playbook from the 19-format catalog for each **section** of hybrid videos.
- Do not force universal fast-cut, meme, or subtitle styles.
- Preserve meaning, chronology, and evidence integrity (release-blocking for news/documentary/react).

## After guidelines

Proceed with `/avo.pipeline` or `/avo.trim` once the user approves the diagnosis.

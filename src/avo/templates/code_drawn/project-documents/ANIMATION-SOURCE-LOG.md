# Animation source log

The generic starter source is distributed with AVO under the repository license.
Its colors and text are examples, not claims about a provider or real product.

Record every added image, SVG, font, drawing library, source-derived still,
reference and generated asset with its source, fingerprint, license/rights,
restrictions, modifications and relevant disclosure. Actual optional brush
bytes and their license are retained locally when that route is selected.

Prior proofs and delivery exports are review references, not source ancestors.

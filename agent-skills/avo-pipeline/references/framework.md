# /avo.framework reference

**Motion engine gate:** Apply [shared arguments](arguments.md) and inspect native
`animation engine-show` with available context before motion-specific skill/setup.
HyperFrames remains the built-in default. For selected code-drawn, follow the
[advanced workflow](code-drawn.md) and common canonical source/review gates.
HyperFrames-only loaders and recipes below apply only to selected HyperFrames.
Unavailable Remotion or incompatible treatments block; never silently substitute.

Inspection and saved preferences need no footage project. Readiness is separate from the recommendation; the current Remotion adapter does not execute renders.

## Step/state mapping

**Durable state:** requested scoped preference files; current run and recorded animation identities when present

**Workflow steps:** Validate framework prerequisites → Run framework → Verify and report the framework result

**Approval or input gate:** Pause whenever required input or a human decision prevents the next declared step; report the exact reply or artifact needed.

**Stop when:** Missing required input, a failed or stale gate, a required human decision, or verified framework completion

**Valid next commands:** /avo.motion or /avo.general

**Motion engine intake**: HyperFrames default, advanced code-drawn, or an explicit Remotion choice with its unsupported AVO adapter disclosed.

## Preconditions

- [ ] Use available provider/project context for authoring; inspection and global preference writes need none
- [ ] Motion need identified (slot, content router, or custom comp)

## Selected HyperFrames intake skill

- **`animation-intake-and-framework-selection`** — recommendation, rejected alternative, license/determinism risks

## Workflow

1. Diagnose format, density, existing project context, license/deployment constraints.
2. Inspect the resolved engine/source/readiness. Explain the default or advanced choice and any capability/license blocker without changing saved preferences unless requested.
3. Write from [`docs/templates/review/framework-selection.md`](../../../docs/templates/review/framework-selection.md) → `<rawDir>/edit/review/framework-selection.md`.

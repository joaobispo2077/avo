# Podcast clip diagnosis (Phase 0)

Load for `/avo.podcast-clip` Phase 0 only — not a standalone command.

## Checklist

| Field | Record |
| ----- | ------ |
| Clip promise | hook + standalone payoff from long-form |
| Speaker context | who is speaking; third-party audio rights |
| Segment bounds | `from`/`to` or phrase anchors |
| Caption intent | identity if burn-in planned |
| Vertical | native 9:16 vs `--vertical` reframe from master |

## Rights posture

- Guest clips, music beds, and reused segments need SOURCE-LOG entries before deliver.
- Prefer `/avo.rights --early` after trim proof for clip-heavy extraction.

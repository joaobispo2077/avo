# TextureCraft material exchange prerequisites

The TextureCraft material profile remains documented knowledge pending native
qualification. It requires a separately installed matching application and
CLI. Inspect the selected release, operation and permitted roots before any
authoring. The documented read and write options for background automation are
`--read-root` and `--write-root`. A live connection has a separate token and
ownership model. [TextureCraft automation](https://craft.wiki/apps/texturecraft/ai-agents/)

For a future native qualification use an owned test project and retain its
model, UV data and material inputs. The documented bake can save in place,
so use a new owned copy. Check numeric color values as linear and hexadecimal
colors as sRGB for the selected command. Inspect the declared packed
texture channel order and transfer against the actual saved textures and
preview. [TextureCraft command and color guidance](https://craft.wiki/apps/texturecraft/ai-agents/)

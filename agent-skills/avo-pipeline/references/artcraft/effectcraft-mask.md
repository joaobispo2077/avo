# EffectCraft masked lower-third review

The selected Windows 0.24.1 CLI operation is `editable-masked-lower-third`.
It requires an independently confined runner and an empty document.
Set `authoringParameters.font` to `Arial` and provide a short printable label
that fits the mask layout. Set `effectFont` to the exact installed Windows
`Fonts/arial.ttf` path and include its parent in the selected read roots.

The output is a 320 by 180 `overlay-video` PNG sequence with straight alpha,
sRGB and a 24 fps clock. The source composition lasts one second. The
standalone export has six frames from the half-open source range 3 through 8.
The adapter checks that frame 3 and elapsed time 0.125 seconds yield the
same first image after reopening. The saved `.ecproj` retains the text and
closed backing mask.

Review both the transparent edge and label readability against a light and a
dark backing. The bounded output holds the label in place. It remains a
standalone review export pending a separate supported program-admission route.

On interruption, inspect the exact job head. An owned runner can settle its
specific active render, with partial files retained as references. A ready
operator handoff needs confirmation from its writer before a new job starts.

# BL-022: Measured motion reference analysis

**Status:** Research proposal, not implemented or scheduled.
**Surface:** Explicit reference-analysis step feeding Direction/Briefstart.
**Source:** [Reference comparison](../../docs/fluxo-de-edicao-comparison.md).

## Gap and outcome

AVO already accepts selected reference descriptions/documents and labels
beat-edit techniques. It does not currently provide the reference repository's
quantitative estimate of camera movement, element movement, easing and duration.
Add bounded measurements from explicitly selected, authorized reference clips.

## Acceptance targets

- Preserve source identity, authorized analysis range and observed sample
  coverage. Produce compact labeled contact sheets and evidence summaries.
- Separate global camera estimates from residual element motion. Record
  confidence/unknowns for cuts, darkness, blur, moving subjects and weak tracking.
- Report measured timing/scale/displacement separately from inferred easing
  families and artistic interpretation. Do not claim exact curves from sparse
  frames or assume every apparent zoom is camera motion.
- Reuse existing frame/audio/scene tooling before adding dependencies; validate
  an initial estimator with known synthetic transforms and ambiguous examples.
- Feed a small inspected document into existing direction/reference selection.
  Do not make Briefstart preparation decode media or fetch nested references.
- Let the creator select or reject reusable observations. Keep brand/design
  authority and current instructions; never mutate a provider profile silently.

Reference media teaches movement, not permission to copy artwork or become a
render source. AVO doctrine and rights/accessibility protections still apply.
